Hastings Chess

Catastrophic Military Stupidity Simulator. Also Axes.

A Battle of Hastings chess variant in which the Saxons can be doing perfectly well until history decides they are not.

Download for Windows ZIP, extract and run Mac, Apple Silicon M1, M2, M3, M4 or later Mac, Intel Older Intel Macs

Not sure which Mac? Apple menu → About This Mac.

The problem

From Saxon move 20, the probability of an involuntary infantry charge starts rising.

By move 30 it reaches 100%.

There is no button marked “Perhaps this is strategically unwise.”

The consequences

Housecarls have axes. Charging pieces push and collide. The Normans then receive a special counterattack with extra knight and pawn actions.

Things tend to become less organised.

Unfortunately, it is an actual game

  • Hastings-aware Fairy-Stockfish opponent
  • 10 difficulty levels
  • Replay analysis
  • Several hundred live and automated tests
  • Native Windows and macOS builds

Genuinely balanced

Both sides can win at every difficulty level.

The Norman advantage increases as the level rises because William did, in fact, win.

This is not currently regarded as a defect.
